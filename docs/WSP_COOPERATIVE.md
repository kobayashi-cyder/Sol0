# Sol0 — WSP 協調生成と微調整（実験）

## モデル境界
外部API・ネットワーク・事前学習済み重みは使用しない。Kimiの視覚専門処理と専門家分割は参考にしたが、Kimiの重み・コードは取り込んでいない。これは学習済み材質パッチを条件付きで合成する**限定的な表面レンダラ**であり、任意の文章から写真を描くAIではない。

## アーキテクチャ
- wsp_scene.js: 境界付き Float32Array scene（深度、法線、アルベド、光学材質、照明、詳細）。プロポーザルを信頼度とWSP寄与率で融合。破損データは統合前に拒否。
- wsp_router.js: 9特徴量×4専門家の重みとバイアスをWSPとして保持。誤差勾配で微調整し、snapshot/restore/rollbackで監査可能。
- wsp_shape_expert.js: 球・平面・立方体近似・角丸タイルの幾何。
- wsp_material_expert.js: 既存のユーザー学習材質パッチをアルベドと粗さ・金属度・透過属性に射影。副材質の空間混合も対応。
- wsp_lighting_expert.js: 法線依存の方向光、拡散反射、鏡面反射、遮蔽の近似。
- wsp_detail_expert.js: 決定的な微細模様とパッチ境界平滑化。
- wsp_critic.js: 法線長、材質属性、光量、境界、極端なアルベド値を監査しrefine maskを出力。
- wsp_cooperative_generator.js: 最大8反復。criticからWSP寄与率を微調整し候補を比較、内部代理スコアの最良候補を返す（改悪した候補は採用しない）。
- cooperative_lab_ui.js: 学習した材質と独立に、協調出力・手動WSP教師信号・自動微調整重み採用・JSON保存・復元を実行。

## 利用
1. メディア工房の「WSP材質学習・生成核」で参考画像を読み込み学習する。
2. 「WSP協調生成・微調整ラボ」で主材質（必要なら副材質）、形状・光・詳細・回数を選ぶ。
3. 「協調生成 PNG」で画像と内部診断を得る。画像は作品領域に保存される。
4. 自動微調整を反映したい場合は「自動微調整重みを採用」、寄与率を手動教師信号で調整する場合は「WSP重みを微調整」を押す。
5. 材質重みJSONと協調WSP重みJSONは**別々**にバックアップする。作品ZIPにはこれらの重みは同梱されない。

## 正直な評価
criticのtotalは数式による**内部アーティファクト代理指標**で、FID、CLIPScore、人手の写実評価、実写写真との比較ではない。反復中に代理指標が改善しても写実的品質の向上を証明しない。材質のroughness / metallicは物体名を使った初期ヒューリスティックであり、写真から物性を厳密に学習した値ではない。複数被写体の構図、人物、自然言語に従う自由生成は未実装。

## 品質保証
Nodeで決定性・範囲外入力・保存/復元・混合・重み微調整・反復単調性を検査。Chromiumでユーザー画像学習→協調PNG生成→作品保存→重み保存を確認。AndroidはCIエミュレーターで基本動作検査、実機性能・写実評価は別途必要。
