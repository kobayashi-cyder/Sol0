# モデルのバイト列を「刺身」のように分割・復元する実験

Sol0のWSPと独立に、Qwen GGUFやKimi safetensorsの**生のバイト列**をチャンクに分け、順序と内容を検証しながら復元する。HEX文字列の2文字は1バイトに対応するので、元の情報を損なわないバイナリ分割が効率的。HEXテキスト化すると約2倍のファイル容量を使うため、HEXの代わりに生バイトをそのまま保存する。

## 実際に試す手順

~~~sh
# 元ファイルは変更せず、8MiBごとの新規バイナリ断片を生成する
node tools/model_chunks.mjs split \
  --input=/models/Qwen3-0.6B-Q8_0.gguf \
  --out=/models/qwen-parts \
  --chunk-bytes=8388608

# 断片の連番、サイズ、SHA256を検証しながら、別の出力に完全復元
node tools/model_chunks.mjs join \
  --manifest=/models/qwen-parts/manifest.json \
  --out=/models/qwen-restored.gguf

# もとのファイルと新しいファイルが1バイトも違わないことを検証
cmp /models/Qwen3-0.6B-Q8_0.gguf /models/qwen-restored.gguf

# 復元モデルを使って実際に推論する（llama-serverが別途必要）
node tools/qwen_local.mjs --model=/models/qwen-restored.gguf
~~~

Kimiのsafetensorsシャードも同じコマンドで分割・復元できる。Kimiで推論する場合は必要なシャードすべてとconfig.jsonなどを揃えたモデルディレクトリを復元し、vLLMを別途起動する。

## 証明したい性質

1. 元モデルの**一切の重みを改変しない**。入力ファイルと既存の出力・保存ディレクトリは上書きしない。
2. 断片ごとに連番、バイト長、SHA256を記録。復元時に全片の内容と全体のSHA256を検証する。
3. 分割・復元時のJavaScript作業バッファーは上限付き（既定64MiB/断片、最大128MiB/断片、復元時のコピー用バッファー1MiB）。巨大モデルを全部Nodeのメモリに展開しない。
4. 断片が欠落・改変・順序変更されたときは失敗し、復元途中の新規ファイルは破棄。元のモデルや既存ファイルには触れない。
5. 元ファイルと復元ファイルの完全なバイト一致を判定し、**復元後のモデルで推論する**。

合成データでの各種破損・復元テストは tests/model_chunks.test.mjs。実データでは、PR #6のqwen-real-e2eジョブが公式Qwen3-0.6B-Q8_0.ggufを取得し、配布元のSHA256を照合した後、8MiB断片に分割して復元、さらに元ファイルとのcmpと復元ファイルのSHA256照合、復元ファイルからの実推論を試す。結果はそのCI実行の成功・失敗で判断し、未完了時には成功扱いしない。

## 何が実現し、何がまだできないか

- **できる**：ファイルをどれだけ細かく分けても、全断片を正しい順序で復元すれば元のファイルに戻せる。分割・復元時のメモリ量は断片サイズ程度に抑制できる。
- **別の技術が必要**：全断片をディスク上に復元せずに、QwenやKimiのTransformerを細切れの重みから直接計算すること。そのためには推論ランタイムが断片対応のメモリマッピング、テンソル単位のロード、キャッシュ破棄、専門家(MoE)の選択とローディングを実装する必要がある。ディスクの読み込み量やOSのスワップ・KVキャッシュ要件が消えるわけではない。
- **実験用の分散設定**：Qwenのllama.cppで --gpu-layers=0 と --cpu-moe-layers=N を、KimiのvLLMで --cpu-offload-gb=N を任意指定できる。これらは別ランタイムのサポートするCPU/GPU負荷分散であって、Sol0の新しい量子化実行エンジンではない。使えるフラグ・RAM/VRAM・速度はモデルとランタイムのバージョン依存。
- **Kimi大型モデルの実推論**：対応GPU・全重み・対応vLLMがないので未実証。分割だけで16B/1兆パラメータの必要演算や巨大なモデル容量が消えることはない。
- **Android**：APKはネットワーク権限なし、Qwen/Kimiの端末内推論は未実装。既存WSP、改行/明示送信、長文履歴、GIF8秒制限は変更しない。

この方式は「単に不可能と決めつけず、バイト単位の分割→無損失復元→本物の推論」という独立に検証できる工程として実装したもの。実Kimiの断片のオンデマンド推論成功を主張しない。
