# WSP材質学習・生成核（実験版）

## 目的と参照
Sol0独自のWSPに、視覚入力から獲得した材質特徴を保存し、外部APIなしで画像を合成する最小の能力を追加する。Kimi-VL / Kimi K2.5の視覚専門処理・専門家選択（MoE）は**分割統治の参考**であり、モデル・事前学習済み重み・実装コードは取り込まない。

参考:
- https://github.com/MoonshotAI/Kimi-VL （MoonViT + MoE）
- https://github.com/MoonshotAI/Kimi-K2.5 （ネイティブマルチモーダル）

## 実装したもの
- chat_web/wsp_materials.js: 8材質の独立したWSP expert。16×16 RGBパッチ×最大16枚/材質、4つの光学・視覚統計値（平均輝度、コントラスト、近傍エッジ量、彩度）を学習。
- chat_web/material_lab_ui.js: メディア工房でPNG/JPEG/WebPを端末内から読み込み、材質を指定して学習、256×256の平面・球面画像を生成。作品としてPNG保存。
- 各 expert は別々の重みとパッチ記憶を持つ。学習のたびに一部パッチを更新。生成時には既習材質を選択し、パッチ境界の色一致を評価しながら再配置し、拡散光・鏡面光の簡易モデルを加える。
- 重みは端末内localStorageに保存し、別JSONとして輸出・復元できる。作品ZIPには重みファイルは自動同梱しないため、JSONも別に保管する。
- SolZero_Chat_Offline.html とAndroid版のビルド入力に組み込み。ネットワークアクセス、外部推論、事前学習済み重みなし。

## 起動と利用方法
1. オフラインHTMLで「メディア工房」を開く。
2. 下部「WSP材質学習・生成核」で材質（肌/石/木/金属/ガラス/水/布/植物）を選択する。
3. その材質が写る参考画像（PNG/JPEG/WebP、8MB以下）を選び「参考画像をWSPへ学習」を押す。
4. 「WSPで画像PNG生成」を押す。学習済み材質の表面が256pxの球体または平面画像として生成され、作品一覧に追加される。
5. 「学習重みJSON書き出し」でバックアップする。復元も可能。

## 品質と限界
この実装は**学習済み画像生成の最初の実験**だが、拡散モデル、VAE、画像意味エンコーダ、文章と画像の対応学習ではない。入力画像からパッチを取り出し再合成するため、人物・風景・物体の自由生成や「実写級」は未達である。パッチに元画像の細部が残ることがあり、機密・権利不明の画像を学習させない。

- 選択した素材以外への一般化は限定的。被写体の意味、光学的一貫性、深度、3D構造は学んでいない。
- 視覚指示への追従、異なる照明、物体配置、写実評価（FID/LPIPS等）は未検証。
- localStorageが使えない端末では重みが永続保存されない。作品ZIPと学習JSONの両方をバックアップする。
- ソフトウェアのCIはブラウザ/Android実機での品質や性能を保証しない。
