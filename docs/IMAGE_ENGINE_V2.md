# Sol0 Scene Director v1 — ローカル画像生成の構図・描画拡張

## 位置付け

従来のMedia Studioは文章から1つのテーマ（海・宇宙・山・森など）を選んで描く手続き型Canvasだった。今回、**複数の主題と位置・前後関係・色・光・画風を組み合わせる独立した構図エンジン**を追加した。

- 学習済み画像モデル、Diffusion、LLM、外部API、ネットワーク、GPUは使わない。
- **写真品質の画像生成AIではない。** 対応した名詞・色・位置・スタイルをルールで抽出する。
- オフラインWSP、Enter改行/明示送信、バックアップ、Android APKの権限は変更しない。
- GIF 8秒上限、動画320×180、画像最大1024×1024、作品ZIPの制約を維持。

## 改善点

| 分野 | 実装内容 |
|---|---|
| 複数主題 | 猫・犬・ロボット・船・家・鳥・人物・車・木・花・雲・月・太陽の13種類 |
| 構図 | 日英の左／右／中央、手前／遠く。最大10主題を位置決定 |
| 色 | 赤・青・黄・緑・紫・ピンク・白・黒を近接語から検出 |
| 光 | 夜・夕焼け・朝・昼に応じたハイライト・装飾 |
| 画風 | イラスト、水彩調、ドット絵風、インク線画風、ネオン調 |
| 奥行き | 遠景・中景・前景の描画順とサイズ調整 |
| 装飾 | 星、微細な光、尾根・前景の草木などのレイヤー |
| 動画 | 既存PNG・GIF・WebMの描画経路に共通適用 |
| 再現性 | 同じ仕様、シード、時刻なら描画コマンド列が一致 |

## 使用例

メディア工房で「生成指示」に入力：

    左に赤い猫、右に青いロボット、夕焼けの海、水彩

「指定からプレビュー」で構図の認識結果（猫・ロボット、watercolor、golden）を確認。「構図サンプルを試す」で同じ入力を自動設定可能。画像PNGで保存。GIF/WebMの各フレームにも場面描画を適用する。

ほかの例：

    星空の宇宙、左に月、右に鳥、ネオン
    手前に犬、遠くに家、森、朝、水彩
    a purple robot on the left, a green tree on the right, calm night neon

## ファイル

- chat_web/scene_director.js — planImageScene と renderDirectedDetails を実装
- chat_web/media_studio.js — 元のテーマ描画の上に構図を適用
- chat_web/media_ui.js — 構図認識の表示、ワンタップサンプル
- scripts/build_standalone.py と SolZero_Chat_Offline.html — 単体オフライン版へ同梱
- tests/scene_director.test.mjs — 複数主題、色、位置、描画再現性、制限値
- scripts/browser_scene_smoke.py — 実Chromiumの描画差、画面表示、PNGエンコード

## 品質と限界

この変更を「学習済み画像AIが完成した」と解釈しない。複雑な人体、物体の相互作用、未知の被写体、写真品質、長文の意味解析は未対応。手続き型ベクターイラストの構図・主題数・多層表現を強化した段階。

受入条件は構図解析、描画再現性、ブラウザ実PNG、GIF8秒、WSP、ZIP/バックアップ、単体HTML一致、Android WebViewの各回帰を個別に判定する。美術的品質の独立評価とAndroid物理端末試験は別作業。
